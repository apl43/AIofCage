# 让本机 AI 调用 Ai of Cage

[文档目录](README.md) · [使用指南](user-guide.md)

设置 → 本机 AI 调用 → 复制 MCP 配置，将配置加入外部 AI 的 MCP 设置。应用二进制以 `--mcp` 启动时只运行控制服务，不打开桌面窗口。开发时也可以使用 `bin/cagectl ai serve`。无需启动桌面应用，不监听 TCP 端口，不新增 API Key；由父 Agent 启动并保持标准输入/输出连接。

典型指令：

> 列出 Ai of Cage 的供应商。使用 DeepSeek 的按量供应商分别创建两个新沙箱，分析不同方案，最多两个任务并发。每个沙箱限制 10 次请求和 30000 token。轮询结果并比较结论，结束后停止两个沙箱。

| 工具 | 用途 |
| --- | --- |
| list_providers | 返回供应商 ID、名称、智能体、模型；无密钥、钥匙串引用或接口地址 |
| create_sandbox | 选供应商、新任务名和可选额度，创建全新停止沙箱。智能体由供应商确定，可指定 sales/incident/release 案例 |
| list_sandboxes | 只列本次连接创建的沙箱 |
| run_task | 异步启动沙箱并执行任务，返回 task_id；可指定模型、思考强度、10—600 秒超时和最多 3 个同 Agent 备用供应商；仅认证、限流、超时或网络失败时按顺序切换 |
| get_task | 轮询 starting/running/done/failed/cancelled、文本、工具名及错误；同时返回 Agent、供应商、模型、耗时和本任务用量 |
| compare_tasks | 按任务 ID 比较同一控制会话中的多个任务，返回状态、Agent、供应商、模型、耗时、请求/token 用量和 500 字输出摘要；不返回完整答案 |
| cancel_task | 取消任务，清理容器内对应 CLI 与工具进程 |
| sandbox_usage | 查询本次连接沙箱的实时模型用量 |
| stop_sandbox | 停止自己的空闲沙箱，保留项目 |

每个控制会话最多创建 8 个沙箱、执行 16 个任务、同时运行 2 个任务；`compare_tasks` 可省略任务 ID 来比较本连接的全部任务，也可显式传入最多 16 个任务；每个沙箱同时一个任务。默认 100 次请求/100000 token，可以调低，不能从接口调高。任务答案最多保存 256 KiB，工具名最多 100 个；截断用 `truncated` 标识。模型计费与桌面相同，额度不是供应商账单的金额上限。

任务为独立实验，不在任务之间复用对话上下文。备用供应商必须属于同一个 Agent；切换前会停止当前沙箱、更新绑定并重新启动，任务结果记录实际供应商和切换原因。桌面结构化会话不使用这条自动切换链。正常 EOF、SIGINT 或 SIGTERM 会取消任务并停止本连接创建的沙箱，项目与用量保留；强制杀进程或系统崩溃不能保证执行退出清理，可在桌面停止残留沙箱。重新连接不会接管旧连接的沙箱；在桌面中仍可查看、启停和删除它们。

数据写入和同一沙箱生命周期使用跨进程文件锁，避免新版桌面、CLI 与控制进程丢失更新或同时重建同一容器。修改存储格式后应重新打开新版桌面，不要同时使用不支持文件锁的旧版。环境启动/替换与空闲停机也使用共享/独占锁。

这个入口解决的是资源选择与实验隔离：父 Agent 可以使用自己的订阅，任务沙箱选择另一供应商的按量资源。子 Agent 采用何种凭据由其 harness 的继承行为决定，不能一概而论；这里通过沙箱绑定独立决定模型请求使用哪个供应商。默认使用所选供应商，只有显式传入 `fallback_provider_ids` 才启用备用供应商；桌面交互会话仍由用户手动选择。

例如先用 `list_providers` 取得同一 Agent 的供应商 ID，再调用：

```json
{
  "sandbox_id": "本控制会话创建的沙箱ID",
  "text": "分析项目并给出结论",
  "fallback_provider_ids": ["备用供应商ID"],
  "timeout_seconds": 120
}
```

故障切换会重新执行同一任务，前一次尝试已经修改的项目文件不会回滚。任务超时覆盖全部尝试；用量累计包含失败尝试。`get_task` 和 `compare_tasks` 返回实际供应商、`fallback_used` 与固定中文切换原因，不返回原始诊断信息。任务对比最多保留 500 个完整字符的输出摘要。

真实重置、原生会话恢复及备用供应商验收入口见[PR 整合验收记录](validation/2026-10-25-pr-integration.md)。

连接有权使用已配置的供应商并消耗额度，限额按本次控制会话计算。服务不返回宿主密钥，不提供任意宿主命令、外部文件挂载或管理已有沙箱的工具；沙箱中的 Agent 仍可以修改当前项目并调用已授权工具，应保留项目备份。
