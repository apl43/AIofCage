# 运行环境资源验证

设置页从专用 Colima 实例读取实际 CPU、内存和磁盘，替换固定的 4/6/40 展示。可以保存 CPU/内存/磁盘期望值，明确显示待应用状态；运行中的虚拟机不立即变更，停止后下次启动沙箱时传给 Colima。没有保存过设置的已有虚拟机保留实际配置，新实例默认 4 CPU/6 GiB/40 GiB。

CPU 不超过宿主核数，内存为 2 至 128 GiB 且给 macOS 留至少 2 GiB，磁盘为 20 至 1024 GiB 且不能缩小已有容量。共享工作区与应用数据位置保持固定；修改路径需要数据迁移，不作为普通资源字段开放。虚拟磁盘上限不同于实际磁盘占用。

“停止运行环境”只停止没有任何运行容器的专用 VM，不替用户停止任务；容器读取失败同样拒绝停机。沙箱启动/智能体更新与停止环境在本进程内互斥，检查实际共享边界后才执行专用实例的停止命令。

验证：

- 真实只读检查得到专用 VM 当前 4 CPU/6 GiB/40 GiB；宿主 24 GiB。临时数据目录保存不同资源后显示待应用，实际 VM 信息逐字段不变；没有改用户持久设置或重启用户 VM。
- CPU/内存边界、磁盘不可缩小、无设置时保留实际值、活跃容器拒绝停机回归通过，相关 runtime/service 竞态、vet/生产构建、JS 语法通过。
- Chrome 合成页面验证资源编辑、保存后的待应用标识、停止确认和活跃容器错误提示。
- 当前用户 VM 有运行沙箱和演示数据库，未执行真实停止/重启；停止分支用受控命令夹具验证拒绝行为。实际 Colima 重新分配资源需在空闲环境验收。
