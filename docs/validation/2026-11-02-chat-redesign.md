# 对话页照 ChatGPT、Claude 桌面端改版

[验收记录索引](README.md)

## 背景

团队觉得沙箱详情的“终端”页不好看，决定参考 ChatGPT 桌面端（OpenAI 官网发布的桌面端截图）和 Claude 桌面端（claude.ai 的对话页和模型菜单，与桌面端同一套界面）改版。用户在截图上标了 5 处，示意图又改过两轮：

- 去掉名字下面的项目路径；六个标签移到右上角，和“停止”“⋯”排成一行。
- 模型、思考强度那一行并进输入框右下角，合成一个按钮。菜单照 Claude 的样式，不要搜索框，保留供应商名，模型直接上下滑动挑；思考强度显示英文原名。
- “添加图片”改成“+”菜单，菜单里只留“添加图片”和“引用项目文件”。添加任意文件另走一个 PR（后端也要改）。
- 删掉“Shift + Enter 换行 · ⌘V 粘贴图片”提示。

借鉴的只是布局和交互，Logo、字体和品牌色仍用我们自己的。

## 改动

- `sandbox-detail.js`：标题行改成“名字和状态｜分段标签、启停、⋯”；项目路径移到“⋯”菜单（在访达中显示项目）和概览页的“项目文件夹”。会话标签栏的“新建”缩成“+”，“在系统终端中打开”“项目文件”改成右边两个图标按钮。
- `composer.js`（新）：输入框从 `sandbox-detail.js` 移出并重做。圆角卡片，输入框随内容变高；左下“+”菜单；右下模型按钮写成“gpt-6.1-sol Low”，菜单顶上是供应商名和刷新，中间是可滚动的模型列表，选中的打勾，最下一行“思考强度 Low ›”向左展开档位；圆形发送键，工作时变成停止键；新会话下面给三条常用任务，点一下填进输入框。
- `conversation-view.js`：消息区居中、最宽 760 像素；你的消息靠右放在气泡里，回复不加框；思考过程和工具活动合成一行“已处理 1 分 12 秒 · 2 次工具活动 · 思考过程”，点开看详情；回复下面加复制按钮（Wails 剪贴板接口）。原来的模型、思考强度和状态那一行删掉。
- `conversation-state.js`：每轮记下开始和结束时间，用来写“已处理多久”；沙箱会话中途结束时也记下结束时间。
- `effort-levels.js`：档位显示英文原名 Off、Minimal、Low、Medium、High、Extra high、Max、Ultra（xhigh 用 OpenAI 自己的写法“Extra high”），Ultra 旁边注明“自动分派子任务”。“模型默认”这一项去掉：CLI 自己的默认档直接打勾并标“默认”，选中它时照旧发送空值，和没动过一样。没有默认档的 dsh 保留一项“默认（由供应商决定）”。
- `main.css`：终端面板改浅色，只有 Shell 的原生终端保留深色；文件栏改浅色；新增菜单、输入卡片、分段标签和图标按钮悬停提示的样式。
- 发出第一条消息后会话锁定：按钮上加锁，菜单只能看，写着“要换模型或思考强度，请新建会话”。这和后端原有的限制一致（继续原生会话时不能改模型和档位）。

### 复查

独立复查（只读代码）指出 8 处，已全部修复并按上表复测：

1. 用鼠标选完模型或档位后焦点被移到模型按钮，接着按回车会重新打开菜单而不是发送。改为只有用键盘选择时才把焦点还给按钮。
2. 教程给输入框加的高亮被 `outline: 0` 盖掉。改为高亮整张输入卡片。
3. 用鼠标打开的菜单按 Esc 关不掉（焦点在输入框里）。菜单打开时在 document 上监听 Esc。
4. 鼠标斜着移向档位菜单时会经过模型行，档位菜单立刻收起。改为离开后等 300 毫秒再收起，进了档位菜单就取消。
5. 窗口矮时向上弹出的模型菜单会被终端面板裁掉。按按钮上方剩下的高度限制菜单，模型列表跟着变矮。
6. 菜单里的禁用项按下去会移动焦点。禁用项不接收鼠标，由外层接住。
7. 去掉标签栏后，进度、操作结果和案例任务贴着下面的内容。加回间距。
8. 文件栏的“插入”按钮和几个禁用的图标按钮带着默认的边框和灰底。去掉。

复查同时确认：没有导入错误和漏掉的重绘；发送选项、刷新模型列表的错误处理、恢复面板、拖入和粘贴图片、把路径插入输入框、教程等待回复的判断都和 main 一致。
