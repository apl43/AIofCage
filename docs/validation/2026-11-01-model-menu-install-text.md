# 终端模型下拉看不清、增装进度文案修复

[验收记录索引](README.md)

## 问题

11-01 决赛前全量实测里的两个小问题：

- **F07**：终端里展开“会话模型”的下拉，白底上的模型名是很浅的灰绿色，投影时几乎看不清。供应商表单里的同一个下拉没有这个问题。
- **F08**：给已停止的沙箱增装智能体时，进度写“准备智能体镜像，当前沙箱继续运行”，和沙箱实际停着的状态不符。

## 原因与改动

- **F07**：下拉 `.model-options` 只设了白色底，文字颜色继承外层。终端里外层是 `.conversation-controls label`，文字色是给深色背景用的 `#c9dcd1`，下拉就成了白底配浅字。改动：`frontend/src/main.css` 给 `.model-options` 指定 `color: var(--ink)`，和页面正文同色。供应商表单里原本继承的就是这个颜色，不受影响。
- **F08**：这句进度在镜像准备开始时显示，运行中和已停止的沙箱都会走到这里。镜像准备期间两种沙箱都不变：运行中的继续运行，到替换容器那一步才停（那一步另有“保存用量并更新容器，终端会话将结束”的提示）；已停止的仍然停着。改动：`internal/runtime/install.go` 改成“准备智能体镜像，完成前沙箱保持原样”，两种情况都成立。

## 实测

- **F07**：用 WKWebView（macOS 26.6.1，WebKit 21624.4.5.11.5，每次不留缓存）加载真实前端和模拟后端，用键盘在终端开一个 Codex 会话，再聚焦“会话模型”输入框，量第一项的文字色和下拉底色：

  | | 文字色 | 底色 | 对比度 |
  |---|---|---|---|
  | main（3d1bb4c） | `rgb(201, 220, 209)` | 白色 | 1.43:1 |
  | 本分支 | `rgb(37, 49, 59)` | 白色 | 13.28:1 |

  截图确认模型名清楚可读。正文文字一般要求对比度至少 4.5:1。
- **F08**：只改了文字，没有重新增装智能体（未缓存的组合要构建约 8 分钟）。`go test ./internal/runtime/` 通过；仓库里没有别处引用这句文字，前端也不按它判断状态。
- 前端 `node --test` 28 项通过，`make check` 通过。

## 范围与限制

- F07 只在 WKWebView 加模拟后端里看过，没在打包好的应用和投影仪上看。
- F08 的新文字没有在真实增装流程里看到过。
