# 初始化安全写入修复

已确认：固定的 `.aiofcage-tmp` 路径会跟随预置符号链接，导致初始化误写 UID 1000 有权写入的其他文件。本项没有证明宿主逃逸或 root 提权。

修复采用逐级、不跟随链接的目录描述符，随机独占创建临时文件，经文件描述符写入及设置权限，再在相同目录描述符下替换目标。证书输出也使用同一路径。JSON 合并保留用户状态，并限制输入类型、层级、体积和文件模式；CA 由 TLS 库解析。

验证：

- `go test ./internal/runtime -run TestAgentInitialization -v`：9 项 Python 安全回归全部通过，覆盖旧临时路径链接、正式目标链接、父目录链接、写入期间父目录替换、随机临时名碰撞、证书输出链接、非法输入、无效 CA、JSON 合并兼容。
- `make check`：Go vet 和 production 构建通过。Wails/macOS SDK 的现有弃用与重复链接警告仍存在。
- `make test`：后端全部包的竞态测试通过。
- 所有攻击夹具只写自动清理的临时目录，不操作用户真实 home、项目或证书。

生效方式：更新桌面应用后，已有运行容器仍使用原镜像；用户下次停止并启动沙箱时，运行时按新内容摘要构建和替换 agent 容器，保留项目及 home 数据卷。不在后台强制重启用户会话。
