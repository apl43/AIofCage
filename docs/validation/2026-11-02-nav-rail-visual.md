# 左侧图标导航与全应用样式

[验收记录索引](README.md)

## 背景

对话页改版（[验收记录](2026-11-02-chat-redesign.md)）的示意图里，左侧导航画成了一列图标。用户确认保留这个样式，并要求像 ChatGPT 桌面端那样，鼠标停在图标上时显示名字。同一批改动里把全应用的控件样式也调轻，和新的对话页一致。

依赖：本分支从 `feat/chat-redesign` 切出，提示气泡的样式在那个分支里加的。

## 改动

- `main.js`：导航只留图标，名字放在 `aria-label`（读屏）和 `data-tip`（悬停提示）里；顶部只留 Logo；底部是使用教程按钮和运行环境状态点，状态点可以用键盘聚焦，提示写“运行环境就绪 · v版本号”。去掉原来的 `title`，免得系统提示和自绘提示同时出现。
- `main.css`：
  - 导航宽 64 像素，图标按钮 40 像素，选中项用浅色底；窄窗口下原来那几条把导航收成图标的规则不再需要，删掉。
  - 提示气泡加一种“在右边”的位置。
  - 按钮高 36、输入框高 38，圆角 10，边框颜色变淡；供应商页的标签页、沙箱列表和用量、日志页的筛选按钮统一成灰底分段按钮；页面标题和标题图标缩小，卡片去掉阴影。
  - 页面边距略收，终端页高度跟着调整，窗口里不出现整页滚动。

## 实测

用 WKWebView（macOS 26.6.1，WebKit 21624.4.5.11.5）加载真实前端和模拟后端，1280×820 逐页截图：

| 页面 | 结果 |
|---|---|
| 沙箱列表 | 导航一列图标，当前页有浅色底；搜索框、筛选按钮和卡片正常 |
| 模型供应商 | 三个智能体的标签是灰底分段按钮，卡片和按钮正常 |
| 工具连接、请求日志、设置 | 排版正常，没有溢出 |
| 沙箱详情的终端页 | 标题行、分段标签、对话和输入框正常，页面不出现滚动条 |
| 悬停提示 | 强制显示“工具连接”的提示：深色气泡出现在图标右侧，不被页面内容盖住 |

- 页面运行中没有脚本错误（模拟后端收集了 `error` 和未处理的 Promise 拒绝）。供应商页起初空白，原因是模拟数据缺 `used_by` 字段；在改动前的代码上同样空白，补上字段后正常。
- 前端 `node --test` 全部通过。
