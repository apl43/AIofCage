# 桌面界面改善验收记录

日期：2026-10-24。范围：统一图标、字体、控件、卡片、表格与终端展示，改善小窗口操作。本次 PR 基于 [品牌与 macOS 图标 PR #35](https://github.com/shaoxier/AIofCage/pull/35)；终端图片功能及原有识图验证见 [PR #34](https://github.com/shaoxier/AIofCage/pull/34)。

## 实现范围

- 导航、页面标题、沙箱、供应商、工具连接、指标和终端操作使用统一的本地 SVG 图标。图标继承文字颜色，不请求在线字体或图标服务；装饰图标不重复朗读操作名称。
- 使用 macOS 系统字体及中文字体回退。正文 15px、辅助文字 13px、页面标题 28px、主要指标 30px；主要按钮至少 40px、输入及选择控件至少 42px。终端文字从 13px 调整为 14px，行高从 1.15 调整为 1.3。
- 加大页面、沙箱和供应商图标，统一卡片留白、选中状态和操作菜单；CPU 与内存的数值和单位保持在一起。健康趋势图高度调整为 144px。
- 精简说明文字，使用“工具连接”等产品名称，应用版本不再展示内部阶段标记。
- 小窗口中指标改为两列，长路径换行，表单标题及底部操作固定；聚焦字段时保留滚动避让空间。终端输入和发送操作在最小窗口中可见。
- 标签页只让选中项进入 Tab 顺序；支持方向键及 Home / End。新增跳到主要内容入口、清晰焦点和有名称的可聚焦表格区域；显式处理 WKWebView 表格方向键横向滚动。
- 保留减少动态效果和高对比度模式的样式。低于桌面最小宽度时也提供布局回退，但本轮未实测这些尺寸。

## 环境与数据边界

正式构建位于 `bin/AIofCage.app`，默认内容区域 1180×800，最小内容区域 900×640。本轮以独立的 `io.aiofcage.ui-uat` 应用验证相同前端及真实后端，仅临时调整应用名、窗口尺寸和应用数据目录；没有使用模拟成功数据。Retina 截图包含原生标题栏，因此对应文件尺寸为 2360×1664 或 1800×1344。

临时数据目录 `/tmp/aiofcage-ui-uat-store` 只复制现有供应商、沙箱和工具连接元数据。未读取、编辑或删除钥匙串内容，未保存供应商表单，未变更沙箱绑定或工具配置。用量页及最近调用展示的内容来自历史记录，本轮没有发送模型请求。

原应用持续运行。原沙箱 `s3-demo` 保持停止、`s9-db` 保持运行；未创建新沙箱或项目目录，未启停、重建或删除容器。仅在原运行沙箱内新开本轮自己的 Shell 和 Harness 会话，结束后通过界面关闭。

## 跳过项与限制

- 本轮图片附件预览：跳过。通过“添加图片”打开原生选择器并定位项目 `AppIcon.png` 后，“打开”仍为禁用状态；已取消。未获得导入结果，未将其判为产品缺陷，也未发送模型请求。图片能力的功能验证沿用 #34，不把该记录计为本轮通过。
- 新模型请求、实际图片识别、完整沙箱创建/增装/启停/删除链路：本轮跳过，范围为前端展示回归。#34 中 Claude 与 Harness 识图通过，Codex 最终识图受七牛上游 502 阻塞，该限制未在本轮解除。
- VoiceOver、200% 缩放、320px 等低于应用最小宽度的窗口、其他操作系统及强制高对比度模式：跳过，未进行实际验收。不据此宣称全面无障碍合规。
